# VoiceInk Offline Premium Version

This is a custom-built offline premium version of VoiceInk with all premium features unlocked and no trial limitations.

## Installation

1. Mount the DMG file by double-clicking it
2. Drag VoiceInk.app to your Applications folder
3. Launch VoiceInk from Applications

## Features Enabled

- ✅ Offline Premium License (no expiration)
- ✅ All premium features unlocked
- ✅ No trial countdown or restrictions
- ✅ Full access to all AI models and modes
- ✅ Unlimited transcription time
- ✅ All power mode features

## System Requirements

- macOS 14.0 or later
- Apple Silicon (M1/M2/M3) or Intel Mac

## Permissions Required

On first launch, VoiceInk will request:
- Microphone access (for voice transcription)
- Accessibility permissions (for automatic text pasting)
- Screen recording permissions (for context-aware features)
